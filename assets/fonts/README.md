# Brand fonts

The workspace uses **Nexa** for English headings and **Graphik Arabic** for Arabic and body text.
If the fonts are installed on your computer they are used automatically. To ship them with the
workspace (for example on a server), copy the files from the brand ZIPs here with these names.
Any of `.woff2`, `.otf` or `.ttf` works.

| File name (any of the three extensions) | Weight |
|---|---|
| `Nexa-Bold` | Nexa Bold (700), headings |
| `Nexa-Heavy` | Nexa Heavy (900), page titles and big numbers |
| `GraphikArabic-Regular` | Graphik Arabic Regular (400), body text |
| `GraphikArabic-Medium` | Graphik Arabic Medium (500), buttons and labels |
| `GraphikArabic-Bold` | Graphik Arabic Bold (700) |

Until then the browser falls back to Segoe UI / the system font.
